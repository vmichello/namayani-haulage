This is an exception review and management pack. It is **not** a statutory audit, tax opinion, or assurance.

## Rules baked into the bots

- Never invent amounts. Label Reported / Calculated / Assumption / AI interpretation.
- Do not create or send invoices.
- If Zoho Books is not exported into the run, output DATA GAP + evidence list.
- At most a few new Linear issues; no duplicate titles.

## Evidence Victor should drop in when asked

Weekly: unpaid estimates, new payments, bank balance.
Monthly: AR ageing, AP, bank rec, GIT bills, VAT position.
